## 1. Visual theme and atmosphere

Plain, calm, trustworthy. The pages are utility stops between a chat and back:
one card, one heading, one action, readable on a phone in a parking lot.
Neutral greys, one blue accent, the device's own font, generous tap targets,
automatic dark mode. Nothing decorative.

### Spacing, radius, elevation

Spacing: 4, 8, 16, 24, 32 px only. Card padding 24px; gap between form
elements 16px; heading to body 8px. Radius: 8px on cards, inputs, buttons,
alerts. Elevation: none; the card is separated by its surface color.

## 3. Layout

- **Page shell:** one centered card, max width 420px, 16px side margin on
  phones, 32px top margin. No header, nav or footer beyond a small product
  name above the card.
- **Breakpoints:** none needed; the single column works from 320px up.
- **Touch targets:** at least 48px high (`--size-touch-target`).

## 4. Components

**`button-primary`**: full width, height 48px, `--color-primary` fill,
`--color-on-primary` text, 16px semibold, radius 8px. Hover and pressed:
`--color-primary-hover`. Focus: 2px `--color-focus` ring, 2px offset.
Disabled: 40% opacity, not clickable. Loading: label replaced with
"Working…" and disabled, to prevent double submits.

**`input-text`** (password or file label): full width, height 48px, 1px
`--color-border` border, radius 8px, 16px text, `--color-bg` fill. Label above
in 14px semibold. Focus: 2px `--color-focus` ring. Error: 2px `--color-danger`
border and the error message below in 14px `--color-danger`, linked with
`aria-describedby`.

**`file-picker`** (upload page only): a `button-primary` labelled "Choose
photos" that opens the device picker (camera roll or camera), accepting
images, multiple. Below it, a list of chosen file names with a count
"3 of 12". Over 12: error state with "Up to 12 photos."

**`alert`**: full-width box, radius 8px, 16px padding, 4px left border in the
state color, text in `--color-text`. Variants: success, warning, danger.
Used for results and errors; announced with `role="status"` (success) or
`role="alert"` (warning, danger).

**`card`**: `--color-surface` fill, radius 8px, 24px padding, holding the page
heading, body and actions.

Empty, loading, error: pages have no data views. Loading is the button's
loading state; errors use `alert` (danger) above the form.

## 5. Accessibility rules

The SRS sets no accessibility NFR; this system adopts **WCAG 2.2 AA** as its
own bar.

- Contrast as computed in §2; never put text on a color not listed there.
- Focus always visible: the 2px ring on every interactive element.
- Touch targets at least 48px.
- Every input has a visible label; errors are text, not color alone.
- Pages work with keyboard only, in a logical tab order.
- Respect `prefers-reduced-motion`; there are no animations anyway.
- `lang="en"`, one `h1` per page, and a page `<title>` that names the step.

## 6. Voice and microcopy

The same voice on pages and in chat (see `ux-foundations.md` Part B1): plain,
short, friendly, no jargon.

- **Do:** "That password isn't right. Try again." **Don't:** "Authentication
  failed (401)."
- **Do:** "eBay connected. You can close this page." **Don't:** "OAuth
  authorization code exchange succeeded."
- **Do:** "Too many tries. Go back to your assistant and connect again."
  **Don't:** "Rate limit exceeded."

## 7. Do's and don'ts

- **Do** use tokens for every color, size and space; never raw values.
- **Do** keep one card, one heading and one primary action per page.
- **Do** say what to do next on every result or error.
- **Don't** add navigation, logos, images or web fonts.
- **Don't** show codes, tokens or technical detail to members.
- **Don't** add colors or component variants outside this file.

## 8. Agent quick reference

- Page = centered `card` (max 420px) on `--color-bg`, heading 24px semibold.
- Primary action → `button-primary`, full width, 48px.
- Input → `input-text`, label above, error below in `--color-danger`.
- Result or error → `alert` (success, warning, danger).
- Font: `--font-family-sans`, body 16px / 1.5. Spacing: 8 / 16 / 24.
- Dark mode is automatic via `prefers-color-scheme`.
